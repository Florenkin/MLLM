# MLLM — Monocular Line Laser Measurement

空气场景单目线激光测量桌面软件。C++17 / Qt 5.15 / OpenCV，界面参考 HTMSR，中心线和单目射线求交流程参考 UWScan2。所有长度采用毫米。

## 启动

已部署程序：`out/package/MLLM/MLLM.exe`。源码目录可使用 `out/build/release/bin/MLLM.exe`。

主界面：中央“单目 / 点云 / 采集 / 激光线”，右侧“测量工作流”的“标定 / 重建”，底部消息、进度和取消按钮。图像滚轮缩放、左键平移、双击适应窗口；点云左键旋转、右键平移、滚轮缩放、双击复位。三维显示采用 Qt CPU 投影，最多显示 15 万抽样点，导出保留全部点。

## 操作流程

1. 相机标定：在“标定”页选择棋盘图像目录，输入**内角点**列/行数和实测方格边长。至少 5 张有效图，建议 15–25 张覆盖不同位置、深度、倾角。点击“标定相机”，自动保存内参、畸变、整体及逐图 RMS。重新标定相机会清除当前激光面表。
2. 激光平面标定：固定相机、激光器及当前振镜位置。每个棋盘姿态拍一张激光关闭图和一张激光开启图，两次拍摄之间棋盘不能移动。两个目录中的文件名主体必须相同，例如 `off/001.png` 和 `on/001.png`。至少 3 组不同深度/倾角的棋盘；只改变图像内位置可能导致退化。填写当前位置，设置重建页的中心线算法、阈值、ROI、颜色、方向，再点击“标定当前激光平面”。通过亮度差分、棋盘姿态和内角点凸包恢复激光点，采用 0.5 mm 内点阈值拟合平面。文件包含全部已标定位置。对振镜扫描的每个使用位置重复此步骤。
3. 重建：选择图像目录或单帧文件，选择扫描几何，填写起始位置和深度范围，点击“批量重建”或“单帧重建”。图像必须与标定尺寸一致。目录按自然文件名排序。检查“激光线”页叠加图及逐帧报告。
4. 点云：查看相机坐标中的结果，导出 XYZ/TXT、ASCII PCD、ASCII PLY。包围盒给出相机坐标轴方向尺寸。平面测量报告 RANSAC 内点拟合 RMS 和最大残差，不作为全部点的平面度认证。体素降采样使用体素内均值，原始结果文件保留。

## 扫描模型

- 固定激光面：每帧使用“激光起始位置”对应的同一平面；不附加运动变换。没有扫描运动时，多帧只是重复/不同截面数据，不能仅凭图像序号得到完整物体表面。
- 已知平移步距：使用同一个激光面；第 `i` 帧输出点增加 `i × 有符号步距`，沿所选相机坐标轴。此步距代表**从相机坐标映射到统一物体坐标的平移**；物体实际移动时通常需要使用反号。若运动轴不与相机轴重合，需要扩展为完整外参变换。
- 振镜 / 逐位置激光面：第 `i` 帧使用 `起始位置 + i × 位置增量` 对应的标定平面。位置单位自行一致约定，例如度；查表必须准确匹配（容差 1e-6），无插值或外推。缺失位置在处理前报告。软件当前提供离线几何，不自动驱动振镜运动。

相机坐标：X 向图像右，Y 向图像下，Z 沿光轴向前。平面为 `aX+bY+cZ+d=0`，法向量归一化。像素通过 `undistortPoints` 得到 `(x,y,1)` 射线，深度 `Z=-d/(ax+by+c)`；剔除平行射线、负深度和超范围深度。

## 采集

支持海康 MVS（GigE/USB3）、USB/DirectShow 通用相机，以及模拟线激光。点击刷新、选择设备和曝光/增益，再连接预览。海康使用自由取流，支持 Mono8 及 SDK 可转换为 BGR8 的像素格式。修改曝光后停止并重新连接。USB 曝光单位依厂商后端不同，本版不设置 USB 曝光/增益。

“新建会话”创建独立目录；“采集一帧”按选择类别保存到 `camera/off/on/reconstruction`，各自从 `000001.png` 编号。激光开关由用户/外部设备操作，软件不控制激光输出；开关两类需按相同棋盘姿态顺序采集。当前没有工业相机硬触发、振镜串口、运动控制和连续同步扫描控制，需按实际硬件协议后续接入并实机验证。

## 数据与配置

标定 YAML 使用 schema 1、medium air、units mm。可导入 UWScan2 的 `CameraMatrix/DistCoeffs/picSize` 作为相机内参；其水下折射参数和二次/四次曲面不转换为空气激光面，仍需进行 MLLM 激光面标定。

每次算法运行创建独立结果目录，保留 YAML、逐图误差/逐帧状态、点云、可选叠加图和重建参数。批量处理中个别坏图继续处理并报告，全部失败则明确报错。取消为协作式，OpenCV 标定求解和文件写入期间需等当前调用结束；已生成的部分结果保留，但不作为完整成功结果。

配置位于可执行文件相邻 `config/settings.ini`，默认值来自 `config/defaults.ini`。环境变量 `MLLM_CONFIG_DIR` 可指定独立配置目录；相对路径基于配置目录的父目录。参数改变后延时保存，退出时保存；日志位于该父目录下 `log`。QSettings 采用原子更新，保留未知键，不保留 INI 手写注释。

## 构建与测试

在 Visual Studio 安装 C++ 桌面工具。复制 `config/defaults/environment.ini` 到 `config/environment.ini` 并填写 Qt5/OpenCV/Ninja/VS_ROOT；可关闭 `MLLM_ENABLE_HIK`，不链接 MVS。模板中的路径是本机示例。

```powershell
powershell -ExecutionPolicy Bypass -File ./build.ps1 -Configuration release -Package
powershell -ExecutionPolicy Bypass -File ./build.ps1 -Configuration debug
```

脚本初始化 MSVC 环境、配置、编译、执行 CTest；Release `-Package` 部署便携目录。构建产物仅在 `out`。核心层不依赖 Qt UI，采集隔离 SDK，服务编排保存结果，UI 提供参数快照和后台任务。测试包括合成棋盘及激光对、亚像素中心线、几何、异常参数、文件往返、取消、模拟采集、UI 离屏启动。

演示数据生成：`out/build/release/bin/mllm_tests.exe --generate-demo <全新目录>`。打开演示：`MLLM.exe --demo <演示目录>`；增加 `--demo-run` 会使用演示标定重建并显示点云。交付目录包含 demo，可运行 `powershell -ExecutionPolicy Bypass -File ./LaunchDemo.ps1`。数据棋盘为 9×6 内角点、20 mm 方格；仅供软件流程演示，不用于真实设备。

## 适用范围与待验收

本版实现空气固定/逐位置**平面**激光模型，不实现水下折射及曲面标定。真实精度取决于相机、镜头、棋盘尺寸、激光条纹、扫描机构和标定覆盖。自动化合成测试只验证软件与数学流程；标准件精度、重复性、硬件触发和现场扫描需实际数据验收。详见 TASKS.md。
