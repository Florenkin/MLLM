# MLLM — Monocular Line Laser Measurement

空气场景单目线激光测量桌面软件。C++17 / Qt 5.15 / OpenCV，界面参考 HTMSR，中心线和单目射线求交流程参考 UWScan2。所有长度采用毫米。

## 启动

已部署程序：`out/package/MLLM/MLLM.exe`。源码目录可使用 `out/build/release/bin/MLLM.exe`。

主界面：中央“单目 / 点云 / 采集 / 激光线”，右侧“测量工作流”的“标定 / 重建”，底部消息、进度和取消按钮。图像滚轮缩放、左键平移、双击适应窗口；点云左键旋转、右键平移、滚轮缩放、双击复位。三维显示采用 Qt CPU 投影，最多显示 15 万抽样点；框选按全部原始点计算，导出也保留全部点。框选模式下左键拖动矩形，关闭框选后左键旋转。

## 操作流程

1. 相机标定：在“标定”页选择棋盘图像目录，输入**内角点**列/行数和实测方格边长。至少 5 张有效图，建议 15–25 张覆盖不同位置、深度、倾角。点击“标定相机”，自动保存内参、畸变、整体及逐图 RMS。重新标定相机会清除当前激光面表。
2. 激光平面标定：固定相机、激光器及当前振镜位置。每个棋盘姿态拍一张激光关闭图和一张激光开启图，两次拍摄之间棋盘不能移动。两个目录中的文件名主体必须相同，例如 `off/001.png` 和 `on/001.png`。至少 3 组不同深度/倾角的棋盘；只改变图像内位置可能导致退化。填写当前位置，设置重建页的中心线算法、阈值、ROI、颜色、方向，再点击“标定当前激光平面”。通过亮度差分、棋盘姿态和内角点凸包恢复激光点，采用 0.5 mm 内点阈值拟合平面。文件包含全部已标定位置。对振镜扫描的每个使用位置重复此步骤。
3. 重建：选择图像目录或单帧文件，选择扫描几何，填写起始位置和深度范围，点击“批量重建”或“单帧重建”。图像必须与标定尺寸一致。目录按自然文件名排序。检查“激光线”页叠加图及逐帧报告。
4. 点云：查看相机坐标中的结果，导出 XYZ/TXT、ASCII PCD、ASCII PLY。包围盒给出相机坐标轴方向尺寸。平面测量报告 RANSAC 内点拟合 RMS 和最大残差，不作为全部点的平面度认证。可框选、提取选区、仅对选区拟合平面，以及按 X/Y/Z 轴裁剪。体素降采样使用体素内均值；裁剪、选区提取和降采样均生成独立点云条目，可通过顶部列表回到原始数据。拟合结果只对应当前条目。

## 扫描模型

- 固定激光面：每帧使用“激光起始位置”对应的同一平面；不附加运动变换。没有扫描运动时，多帧只是重复/不同截面数据，不能仅凭图像序号得到完整物体表面。
- 已知平移步距：使用同一个激光面；第 `i` 帧输出点增加 `i × 有符号步距`，沿所选相机坐标轴。此步距代表**从相机坐标映射到统一物体坐标的平移**；物体实际移动时通常需要使用反号。若运动轴不与相机轴重合，需要扩展为完整外参变换。
- 振镜 / 逐位置激光面：第 `i` 帧使用 `起始位置 + i × 位置增量` 对应的标定平面。位置单位自行一致约定，例如度；查表必须准确匹配（容差 1e-6），无插值或外推。缺失位置在处理前报告。软件当前提供离线几何，不自动驱动振镜运动。

相机坐标：X 向图像右，Y 向图像下，Z 沿光轴向前。平面为 `aX+bY+cZ+d=0`，法向量归一化。像素通过 `undistortPoints` 得到 `(x,y,1)` 射线，深度 `Z=-d/(ax+by+c)`；剔除平行射线、负深度和超范围深度。

## 采集

支持海康 MVS（GigE/USB3）、USB/DirectShow 通用相机，以及模拟线激光。点击刷新、选择设备和曝光/增益，再连接预览。海康使用自由取流，支持 Mono8 及 SDK 可转换为 BGR8 的像素格式。修改曝光后停止并重新连接。USB 曝光单位依厂商后端不同，本版不设置 USB 曝光/增益。

“新建会话”创建独立目录，绑定相机和图像尺寸。相机标定图及重建图像分别保存到 `camera/reconstruction`，从 `000001.png` 编号。激光标定按组采集：选择“激光关闭”，关闭图先暂存在 `pending`；界面自动切换并锁定“激光开启”。保持棋盘静止、开启激光后再采集，成功后同名图像共同登记到 `off/on`，界面回到下一组的关闭图。相机重连、重复帧或曝光/增益变化不能完成旧组。未完成组可显式放弃，暂存图保留供检查；保存失败会尝试回滚，未完成组不进入标定目录。激光开关由用户/外部设备操作，软件不控制激光输出。每次保存会原子更新 `capture_manifest.yml`，记录设备、连接批次、帧号及其来源、主机接收时间、请求曝光/增益、丢包数、保存序号、配对号和扫描模型。主机时间不是硬件触发时间。重建图像默认按当前扫描参数记录计划位置；可勾选人工位置输入，记录本帧激光位置或平移量。计划/人工位置不代表编码器反馈。

有采集记录的单帧和批量重建均使用记录位置；批量重建按保存序号处理，校验目录、扫描模型、坐标轴、缺失或未登记图像；结果目录保留采集记录；批量 `frames.csv` 包含平移量，单帧参数记录实际使用的位置及平移量。旧数据可继续使用：运动扫描按文件顺序推算位置并发出警告，可识别的数字序号跳变会直接报错。当前没有工业相机硬触发、振镜串口、运动控制和连续同步扫描控制，需按实际硬件协议后续接入并实机验证。

## 数据与配置

标定 YAML 使用 schema 1、medium air、units mm。可导入 UWScan2 的 `CameraMatrix/DistCoeffs/picSize` 作为相机内参；其水下折射参数和二次/四次曲面不转换为空气激光面，仍需进行 MLLM 激光面标定。

每次算法运行创建独立结果目录，保留 YAML、逐图误差/逐帧状态、点云、可选叠加图和重建参数。批量处理中个别坏图继续处理并报告，全部失败则明确报错。取消为协作式：点云导入、体素、框选、裁剪、平面拟合和导出循环均检查取消；OpenCV 原生求解、单次编码/写盘仍需等当前调用结束。后台任务统一区分成功、失败和取消，并捕获标准及未知异常；关闭窗口会取消并等待线程释放。已生成的部分结果保留，但取消不写完成标记。点云导出采用临时文件原子提交，中途取消保留原目标文件。

配置位于可执行文件相邻的 `config`，分为 `calibration.ini`、`laser.ini`、`reconstruction.ini`、`acquisition.ini`、`paths.ini`；注释模板在 `config/defaults`。首次启动从有效的旧 `settings.ini/defaults.ini` 迁移缺失的分类文件，旧文件保留，分类文件优先。环境变量 `MLLM_CONFIG_DIR` 可指定独立配置目录；相对路径基于配置目录的父目录。

配置服务校验类型、范围和有限数值，异常值采用合法默认值并记录警告。保存采用 UTF-8 和原子替换，保留整行注释、未知键；重复键、格式损坏或编码错误会阻止覆盖该文件并报告错误。参数改变后延时保存，退出时保存；分类文件分别提交。`paths/restoreInputPaths=false` 可关闭输入路径恢复。日志目录配置为 `paths.ini` 的 `[paths]` / `logDirectory`，本工程默认 `C:/Project/MLLM/log`；修改后重启生效。

## 日志

参考 HTMSR，统一 `Logger` 将日志同时发送到 UTF-8 文件和底部“消息”表格。每次启动创建独立文件 `log/mllm_yyyyMMdd_HHmmss_zzz.log`；同一毫秒启动时追加编号，已有文件不会被覆盖。文件记录包含完整日期、毫秒时间、级别、模块和消息，多行内容转义为 `\n`/`\r`，每条日志写入后立即刷新。文件接收器在主窗口创建前启用，在后台任务和窗口销毁后关闭，保留启动和正常退出记录。

日志目录由 `config/paths.ini` 的 `[paths]` / `logDirectory` 控制；迁移前兼容旧 `settings.ini`，本工程默认为 `C:/Project/MLLM/log`。可填写绝对路径；相对路径以配置目录的父目录为基准。启动时仅清理符合 `mllm_yyyyMMdd_HHmmss_zzz[_编号].log` 命名规则且最后修改时间超过 24 小时的文件；旧版每日 `MLLM_yyyyMMdd.log`、其他文件和目录保留。目录创建或写入失败会通过消息面板报告，算法和采集仍可运行。

级别为 Debug、Info、Warning、Error，普通文件和界面过滤 Debug；取消任务和跳过坏图使用 Warning，操作失败使用 Error。模块包括 App、Logging、Config、Camera、Capture、CameraCalibration、LaserCalibration、Reconstruction、PointCloud。标定和重建记录输入目录、约每 10% 的进度、结果、错误原因和结果目录。相机记录连接、停止和取流异常。

消息面板为“时间 / 级别 / 模块 / 消息”四列，默认显示两行，可拖高、滚动查看历史。界面保留最近 2000 条记录，警告和错误用颜色区分；悬停消息可查看原文。完整 Info/Warning/Error 记录保存在文件中。后台日志通过 Qt 队列送至界面线程。

代码使用 `mllm::Logger::instance().info("模块", "UTF-8 消息")`；也提供 `debug`、`warning`、`error`。核心 Logger 不依赖 Qt，文件接收器和界面接收器各自注册、注销，互不影响。

## 构建与测试

在 Visual Studio 安装 C++ 桌面工具。复制 `config/defaults/environment.ini` 到 `config/environment.ini` 并填写 Qt5/OpenCV/Ninja/VS_ROOT；可关闭 `MLLM_ENABLE_HIK`，不链接 MVS。模板中的路径是本机示例。

```powershell
powershell -ExecutionPolicy Bypass -File ./build.ps1 -Configuration release -Package
powershell -ExecutionPolicy Bypass -File ./build.ps1 -Configuration debug
```

脚本初始化 MSVC 环境、配置、编译、执行 CTest；Release `-Package` 部署便携目录。构建产物仅在 `out`。核心层不依赖 Qt，采集隔离 SDK，任务执行器不持有窗口或控件。配置、采集会话、点云文档/操作和结果导出各由独立服务负责，点云面板只接收只读数据及参数快照。任务类型和结果状态使用枚举，大点云以共享只读快照交付，派生条目保留来源。

CTest 包含 `geometry_and_workflow`、`ui_smoke`、`ui_workflow`、`logging`、`stability`，覆盖合成几何、按钮闭环、日志、配置迁移与保护、采集回滚、逐帧位置、处理中途取消和线程生命周期。

演示数据生成：`out/build/release/bin/mllm_tests.exe --generate-demo <全新目录>`。打开演示：`MLLM.exe --demo <演示目录>`；增加 `--demo-run` 会使用演示标定重建并显示点云。交付目录包含 demo，可运行 `powershell -ExecutionPolicy Bypass -File ./LaunchDemo.ps1`。数据棋盘为 9×6 内角点、20 mm 方格；仅供软件流程演示，不用于真实设备。

## 适用范围与待验收

本版实现空气固定/逐位置**平面**激光模型，不实现水下折射及曲面标定。真实精度取决于相机、镜头、棋盘尺寸、激光条纹、扫描机构和标定覆盖。自动化合成测试只验证软件与数学流程；标准件精度、重复性、硬件触发和现场扫描需实际数据验收。详见 TASKS.md。
